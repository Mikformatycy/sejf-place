# sejf-place

_Na telefonie: „Pocket” (iPhone) albo nazwa wybranej przykrywki (Android)._

**Dowody, których sprawca nie znajdzie, nie usunie i nie podważy.**

Co piąta kobieta w UE doznała przemocy ekonomicznej od partnera. Od 2023 r. polskie prawo uznaje ją za przemoc domową, ale trudno ją udowodnić: sprawca przegląda telefon, a dowody znikają.

sejf-place wygląda jak zwykła aplikacja (przepisy, urodziny i inne) i naprawdę nią jest. Sejf otwiera tylko sekretna czynność, np. twaróg w serniku ustawiony na 1250 g.

- szyfrowane zdjęcia, nagrania, dokumenty i notatki
- znacznik czasu RFC 3161 dla każdego wpisu
- raport zgodny z „Niebieską Kartą” i pakiet dowodów do sprawdzenia bez aplikacji
- szybkie wyjście: potrząśnij telefonem

## Start

```bash
npm install
npx expo start
```
